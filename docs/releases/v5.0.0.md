# Solus v5.0.0 Release Notes

**Version:** `5.0.0`  
**Version Code:** `8`  
**Target SDK:** Android 15 / 17 (API 37)  
**Min SDK:** Android 9.0 (API 28)  
**Architecture:** `arm64-v8a` (16 KB page-size compliant)  
**License:** Apache 2.0  

---

## Overview

Solus **v5.0.0** is a major production-hardening release focused on end-to-end inference reliability, transactional model management, memory safety, decompression bomb defense, strict cryptographic update verification, and audio recording efficiency.

This release hardens the core local AI orchestration across text, vision, audio, and document workflows, ensuring that every safeguard is fully enforced across production code paths.

---

## Key Highlights & Improvements

### 1. Robust Response Finalization & GPU-to-CPU Retry Isolation
- **Sanitized Answer Extraction:** Inference managers now track distinct raw, reasoning, and accepted-answer streams per request attempt. Reasoning-only output can never masquerade as an accepted answer.
- **Reasoning-Only EOF Protection:** Completed generations containing only thinking tokens without final answer text are cleanly handled as `Failed` with `Reason.EMPTY_RESPONSE` rather than corrupting conversation history with blank replies.
- **Isolated Attempt Lifecycle:** Introduced `beginAttempt(attemptId)` on `InferenceResponseController`. When GGUF GPU execution encounters errors and falls back to CPU recovery, all attempt-local buffers, controller states, and publisher snapshots are cleared simultaneously.
- **Strict Attempt Identity:** Stale callbacks carrying obsolete request IDs or attempt IDs from preceding GPU attempts are rejected immediately.
- **Efficient Streaming Parser:** Streaming response publisher appends tokens under synchronization and parses formatting at stable publication cadences rather than reparsing accumulated streams on every individual token.

### 2. Transactional Model Publication & Artifact Integrity
- **Non-Mutating Lookups:** Model storage lookups strictly separate read-only queries from directory creation, eliminating false "downloaded" states for missing models.
- **Generation-Based Atomic Publication:** Model files and extracted archives are published into unique generation directories (`gen_<timestamp>_<uuid>`), fully validated against their manifests, and atomically promoted.
- **Failure Resilience:** Existing model artifacts and manifests remain untouched if a replacement download, extraction, or validation fails or is cancelled.
- **Archive Validation:** ZIP archive SHA-256 digests are verified against the downloaded archive before extraction, followed by structural directory verification.

### 3. Resumable & Cancellable Download Engine
- **Strict Resume Validation:** Download resumption validates server `ETag`, `Content-Length`, and `Last-Modified` headers against stored resume tokens. If the remote resource changes or responds with `200 OK` instead of `206 Partial Content`, partial buffers are cleanly reset.
- **Responsive Cancellation:** Cancelling an in-flight download immediately closes underlying HTTP streams, deletes transient `.part` files, and prevents orphan background network usage.

### 4. Download Command Serialization & Foreground Service Reliability
- **Command Serialization:** All download management commands (start, pause, resume, cancel) are serialized to eliminate race conditions between user interactions and worker coroutines.
- **Foreground Service Lifecycle:** `ModelDownloadService` guarantees prompt foreground notification promotion within system deadlines and performs clean self-termination upon completion or cancellation.

### 5. Thread-Safe Native Runtime Ownership & Teardown
- **Synchronized Context Teardown:** Native inference contexts in `LlamaNativeBridge` and MediaPipe/LiteRT engines feature thread-safe state machines and synchronized teardown.
- **Double-Free & Crash Prevention:** Prevents race conditions during model unloading, session switching, and background app pausing, ensuring clean native memory deallocation without `SIGSEGV` faults.

### 6. Persistence Recovery & Non-Blocking Disk Operations
- **Off-Main-Thread Disk Writes:** All persistent session, memory, and settings writes are strictly dispatched to background IO threads.
- **Atomic File Swaps:** Session serialization uses atomic write-to-temp-and-rename semantics to prevent corrupted JSON state during abrupt process termination.
- **Corrupted State Fallback:** Automatic recovery logic safely resets corrupted conversation files to clean default states without crashing the application.

### 7. Reliable Message Retry with Durable Attachments
- **Context Preservation:** Retrying an assistant turn correctly identifies the target user turn, truncating downstream history while strictly preserving the original prompt text.
- **Durable Attachment Reconstruction:** Attached images, documents, and audio recordings are re-resolved and re-bound from persistent storage for the retried inference request.
- **Engine State Reset:** Retry calls explicitly pass `isRetry = true` to inference engines, resetting stateful conversation runtime context and preventing context drift or duplicate prompt accumulation.

### 8. Document Extraction Safety & Decompression Bomb Protection
- **Unified Extraction Budget:** `DocumentExtractionBudget` enforces strict aggregate limits:
  - Maximum uncompressed text: 20 MB
  - Maximum scanned entries: 10,000 entries
  - Maximum folders: 1,000 folders
  - Maximum files: 2,500 files
  - Maximum output characters: 200,000 characters
  - Strict extraction deadline: 15 seconds
- **Nested Archive Denial:** Disallows nested archives (`.zip`, `.tar`) to prevent recursion bombs while securely supporting nested Office XML containers (DOCX, PPTX, XLSX) under shared budget accounting.
- **Bounded Streaming Extraction:** Replaced unbounded buffer reads with streaming bounded readers across PDF, DOCX, PPTX, XLSX, ODT, ODS, ODP, and plain text files.

### 9. Cryptographic Update Verification & Audio Memory Safety
- **Strict Signer Set Verification:** `UpdateArtifactVerifier` requires an exact match between installed and candidate APK signing certificate sets (`toSet() == toSet()`). Closes bypasses on empty signatures or mismatched auxiliary certs.
- **Secure Update Delivery:** Enforces HTTPS for release assets and canonical directory path containment for downloaded APK files.
- **Reduced Audio Buffer Footprint:** Corrected `PcmRecorder` buffer allocation arithmetic from unbounded integer overflow (~32 MB) to bounded exact byte capacity (~960 KB for 30s audio at 16 kHz 16-bit mono).
- **Guaranteed Recorder Cleanup:** Wrapped audio recorder operations in guaranteed `try-finally` blocks ensuring `recorder.stop()` and `recorder.release()` execute reliably even if buffer allocation or recording fails.

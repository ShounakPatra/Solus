## Import your own models

- Import compatible `.gguf`, `.litertlm` and `.task` files from phone storage, with file-content format detection.
- Select split GGUF shards and compatible companion projectors together. Preserve storage access and relink files when needed.
- Import from Hugging Face repositories, variants and direct URLs, with revision resolution, optional gated/private access tokens and available checksum verification.
- Start accepted remote downloads immediately. Cancelling retains the imported entry and resumable download data.
- Apply device/RAM load restrictions separately after acquisition, with a visible reason rather than replacing download progress.
- Find models using Imported tags/filter and a chooser containing downloaded catalog and imported models.
- Use the glass Add model control, wider URL field and full-width Add & download action, with clearer format, shard and access errors.
- Preserve import drafts, coordinate sessions, reject duplicate submissions and clean up storage permissions more carefully.

## Thinking, streaming and runtime recovery

- Unify capability handling and refresh capability metadata for existing models without requiring another import or download.
- Add a compatibility fix for the catalog's legacy Qwen 3 0.6B export.
- Separate reasoning from final answers, prevent duplicate reasoning display and improve Thinking-off and Stop behavior.
- Classify reasoning from verified prefilled thinking prefixes and preserve literal trailing stream characters, including `<`.
- Restore initialized thinking/media capabilities after on-demand reloads.
- Harden malformed model metadata and reject invalid non-GGUF split/projector bundles.
- Improve initialization, shutdown, runtime handoff and elapsed-wait reporting.
- Allow an explicit Try Anyway retry after a device warning or previous native initialization crash. Clear the device-local crash block after successful initialization; retrying is not a compatibility guarantee.
- Repair native integration paths for encoder batch bounds, multimodal context reservation, metadata and shutdown. Debug assembly includes DEX integrity verification.
- Replace Haze 1.5.1's broad consumer optimization rule with a logging-only rule, avoiding inherited `Object` method matches during release shrinking.

## Chats, memory and documents

- Search titles and message content; pin and rename conversations in tidier history cards with glass menus and dialogs.
- Edit earlier prompts and regenerate replies using compact message actions.
- Enable or disable temporary chat on a new, empty conversation, with a state notification. Temporary chats skip saved history and memory extraction.
- Preserve temporary-chat intent during model selection and leave temporary mode when opening saved history.
- Export and restore chats, saved memories, settings and optional available attachments. Exclude model weights, access tokens and document indexes.
- Save per-model instructions, context limits and supported sampling settings.
- Show estimated context use inside telemetry only for initialized models, using actual runtime capacity including fallbacks.
- Inspect retrieved document passages through Sources controls.
- Reject malformed persisted history and knowledge-base data and block writes until recovery succeeds; preserve deletion recovery safeguards.

## Interface and accessibility

- Floating blurred composer, temporary-chat control and media menu, with compact coloured persona/shortcut controls.
- Scrollable starter suggestions and improved empty-state text layout.
- Prevent blank composer areas from activating suggestions underneath.
- Adapt shortcuts and media-menu height when the keyboard is open, retaining access to typed text and the Think control.
- Floating bottom navigation without outer solid backing or background blur; fast sliding selection with spring bounce.
- Isolate page transitions and blur captures to prevent outgoing Model Manager colours flashing into Chat.
- Keep Settings accessible from the chat header when bottom navigation auto-hide is enabled.
- Group Data, Models, Storage and Accessibility settings into separate cards; add storage breakdown, cache cleanup, reduced-motion and larger-touch-target options.
- Animate model and import-source tab selection and disable unavailable thinking controls with a subdued appearance.

## Runtime baseline and future work

LiteRT-LM is configured at **0.18.0**; the llama.cpp integration declares pin **5cdadfc326163ed1fa66cf609fb1761f7928900c**. These are baseline identifiers, not claims that they are the newest upstream versions.

The v6.0.0 source includes CPU isolation configuration/checks, conservative Auto selection, a CPU/GPU benchmark with saved performance receipts, prompt-prefix reuse, runtime handoff guards and timing/trace instrumentation. Further runtime upgrades, measured GGUF optimizations, benchmark measurement audits and broader device validation are planned for v6.0.5 in the [roadmap](https://github.com/ShounakPatra/Solus/blob/main/README.md#roadmap). Source implementation alone does not prove an on-device performance gain.

- [Android CI passed for commit `e9a01c0`](https://github.com/ShounakPatra/Solus/actions/runs/39578235174): host C++ native tests, APK-checker regressions, Android unit tests, lint, instrumentation-test compilation, debug/release APK builds, and APK size/structure verification all succeeded.

- The signed release APK passed signature and DEX integrity checks. Its saved R8 configuration contains the narrow Haze logging rule rather than the unsafe wildcard. The published file matches its verified hash.
- CI compiles instrumentation tests but does not execute them on a device. No physical-phone inference test or performance benchmark was performed as part of this documentation update; build success does not establish compatibility with every model and phone.
- Model architecture, quantization, projector, RAM and drivers determine compatibility. Try Anyway can still fail or crash on an unsupported device; successful initialization clears the recorded crash block.
- Backups exclude model weights, access tokens and document indexes. Unavailable attachments cannot be included.

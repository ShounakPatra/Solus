# Solus v6.0.1

Patch source: **6.0.1**, Android version code **10**. These notes prepare the next release; the published v6.0.0 APK is unchanged.

## Fixes

- **Compatible backup settings:** unknown setting keys are ignored, missing keys preserve the destination's current values, and known supplied keys still require valid types and ranges. Regression coverage includes restoring a v6.0.0 settings schema with chats and memories.
- **One Hugging Face token:** Settings, model checks, repository imports and downloads use AppSettings as their source of truth. Tokens are encrypted using AES-GCM with an Android Keystore key. Both old preference keys are migrated; when two non-empty legacy values differ, the historical download token takes precedence. Plaintext keys are removed after encrypted storage commits successfully.
- **Larger controls are opt-in:** new installations start with larger touch targets off; existing user choices remain intact.
- **Settings backdrop:** a full-screen opaque window background and independent blur state prevent the underlying Chat/Models screen appearing through the bottom or through cached blur captures.
- **Vision retry:** MediaPipe session retries use a cancellable coroutine delay instead of blocking the thread.
- **Firebase cleanup:** remove the unused `app/google-services.json` and ignore it in future commits. Firebase analytics, measurement connectors, sessions and installations remain excluded. MediaPipe's required Firebase-named encoder serialization helpers are retained; they are not a Firebase analytics/service integration. This does not remove files from historical Git commits.
- **CI resilience:** retry SDK/NDK installation up to three times, avoid the `yes`/pipefail trap, test retry success/failure paths, and use `actions/upload-artifact@v7` consistently.

## Release checks

Android Keystore behavior and the full-screen Settings rendering still require physical-device verification. Host tests exercise token migration using an injected JVM cipher; they do not substitute for Android Keystore tests.

The persisted-URI permission-cap improvement remains follow-up work for v6.1. Issue [#17](https://github.com/ShounakPatra/Solus/issues/17) remains open pending Marigo001's confirmation that model imports work.

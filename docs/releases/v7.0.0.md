## New in v7.0.0

### 🦀 Completely Rebuilt with Rust & Candle (`solus_candle`)

- **Rust-First Portable Runtime:** Core model inference (`text_models`, `media_models`, `media_sessions`, `gpt2`), tensor execution (`candle-core` `0.9.1`, `candle-nn`, `candle-transformers`), tokenizer handling (`tokenizers` `0.21.1`), and multi-threaded `rayon` CPU pooling are powered by Rust.
- **Memory Safety & Panic-Guarded JNI:** All JNI calls across `CandleBridge` use `catch_unwind` boundaries and handle-registry isolation so native errors surface cleanly to Kotlin rather than crashing the JVM.
- **Hardened Archive & Toolchain Pipeline:** Retains pinned Rust `1.90.0` `aarch64-linux-android` builds alongside `llama.cpp` C++/Vulkan, **LiteRT-LM 0.19.1**, and **ONNX Runtime 1.31.1**.

---

### 🎙️ TinyVoca Neural Voice Reading (TTS) & Live Word Highlighting

- **Bundled Zero-Network Voice Model:** Ships the ultra-compact **8.1 MB** INT8 `tiny_voca.onnx` neural TTS model directly inside APK assets so reading answers aloud works completely offline out of the box.
- **Instant RAM Pre-Warming & Speaker Action:** Pre-warms the ONNX session in memory and adds an on-demand speaker button on AI bubbles, supporting **F2 (Female)** and **M2 (Male)** voices and speed multipliers.
- **Live Synchronized Word Highlighting:** Tracks and highlights spoken words in real time with syllable-aware pacing and natural punctuation pauses, complete with an interactive toggle under **Voice & Speech** (searchable in Settings).
- **TinyVoca Management Card:** Monitor live residence status (`Ready`, `In RAM`), run playback tests, delete weights with accidental-deletion confirmation, or restore offline from bundled assets in one tap.

---

### ✨ Liquid Glass UI, Live Aurora & Edge-to-Edge Immersion

- **Immersive Edge-to-Edge Chat Layout:** Removed the legacy bottom navigation bar to maximize reading space, disabled Android API 29+ 3-button nav bar contrast scrims so chat messages scroll behind a **transparent bottom navigation bar**, and kept an opaque status bar + pinned search header scoped strictly to **Model Manager**.
- **Live Glowing Aurora & Full-Screen Blur:** Added `LiveAuroraBackground` ambient color gradients and extended live Haze **1.7.3** blur across the telemetry pill, floating header controls, inline model selector (`+` shortcut to Models), dynamic **New Chat** button, and morphing chat composer.
- **Glass Sliders, Presets & Vice City Temporary Emblem:** Upgraded Chat Defaults (Temperature, Top-K, Max Length, Auto-Unload Timer presets `Off`, `2m`, `5m`, `10m`, `15m`, `30m`) with custom glass sliders, and packaged a temporary **GTA VI Vice City neon sunset** launcher/splash icon set (with `res_original_icons_backup` preserved for easy restoration).
- **Layout & Animation Polish:** Fixed empty-state suggestion vertical shift on composer focus changes and eliminated add-media menu close flicker.

---

### 🧠 Unified Passive Thinking Pipeline & Model Fixes

- **Zero Heuristic Guesswork Across All 4 Backends:** Removed legacy per-model thinking allowlists, regex detectors, SHA-256 profile overrides, and forced `<think>`/meta-instruction prompt injections.
- **Passive `enable_thinking` Forwarding:** Passes your **Think** preference natively into Jinja chat templates (GGUF / ONNX / Candle) and LiteRT-LM (`ThinkingConfig` + `extraContext`) with safe fallback wrappers so models that don't expose thinking ignore it harmlessly and never block inference.
- **Always-On Thought-Block Parser & Unclosed Guard:** Permanently recognizes `<think>...</think>`, `<|channel>thought...<channel|>`, `<|thought|>...<|/thought|>`, and `<thought>...</thought>` into the collapsible **Thinking process** card, with an unclosed opening-tag safety guard so replies never get trapped in empty error bubbles.
- **1-Line Composer Template Check:** Cleanly keeps the composer Think toggle available for templates with thinking markers or unknown templates (passive no-op), hiding it only when a known template lacks reasoning markers.
- **Gemma 3 270M Fix:** Routed Gemma `.task` bundles through LiteRT-LM's native Conversation layer (with MediaPipe CPU fallback), fixing empty and boilerplate acknowledgements.

---

### 🔍 Settings Redesign, Ranked Search & Autonomous Web Search

- **Hierarchical Liquid Glass Settings & Personas:** Grouped Preferences into frosted submenu cards with animated transitions and a dedicated **Personas** submenu.
- **Centralized Multi-Token Ranked Search (`SettingsSearchIndex`):** Automatically syncs with `BuildConfig.VERSION_CODE` and indexes **74+ settings across all 19 submenus** plus your saved model profiles, supporting multi-word relevance ranking and direct deep-linking (e.g., jumping straight to **Providers** from missing HF token alerts).
- **Tool-Free Autonomous Web Search & Test Viewer:** Web search operates seamlessly without forcing manual tool-calling setup, paired with a scrollable Glass UI search test dialog to preview DuckDuckGo queries and raw results.

---

### 📊 Model, Storage & Diagnostics Suite

- **Model & Storage Visualization Cards:** Added `SpecializedModelsMenuCard` (separating auxiliary utilities from chat LLMs), `DeviceStorageCards` (visual breakdown of LLMs, attachments, RAG indexes, RAM headroom, and quick cache clearing), `TinyVocaModelCard`, and expanded `DocumentSearchModelCard` (`potion-base-2M`, ~7.5 MiB offline neural embeddings).
- **Redesigned About Solus & Crash Reports:** Added **Hugging Face Works** showcase, updated **What's New**, revamped glass Performance Benchmark modal, and upgraded **Crash Reports**—replacing *Share* with per-report **Delete** and styling **Send to Repo** with primary Liquid Glass accents.
- **Formal State Machines & CI Notifications:** Introduced observable `ModelState` and `InferenceState` lifecycles, interactive active-model ejection, dependency bumps (**AGP 9.5.2**, **Kotlin 2.4.21**, **Gradle 9.9.2**, **LiteRT-LM 0.19.1**, **ONNX Runtime 1.31.1**, **latexRenderer 1.8.0**, **Haze 1.7.3**), and optional `ntfy.sh` browser notifications on Android CI completion.

## Compatibility and known limits

- Model architecture, quantization, operators, processor files, RAM, and device drivers determine compatibility. Successful import or initialization does not guarantee output quality or speed on every device.
- Tool calling remains model/template-dependent; inspect **Used tool** records rather than treating a plausible answer as tool execution.
- SafeTensors FP32 loading and experimental portable media paths can require significantly more RAM than their on-disk file size.
- Desktop CMake host C++ tests (`app/src/test/cpp`) require a desktop C++ compiler (`g++`, `clang++`, or MSVC) and run on Linux CI rather than Windows hosts without one.

Report issues with the installed version/code, exact model export/revision, device, runtime/backend, Think/tool settings, and redacted diagnostics.

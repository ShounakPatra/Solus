# Solus v7.0.0

Solus v7.0.0 introduces resident on-device neural voice reading and major liquid-glass UI enhancements.

## What's Changed

### 🎙️ TinyVoca Neural Voice Reading (TTS)
- **Compact On-Device Neural Voice:** Bundled the ultra-compact 8.1 MB INT8 TinyVoca ONNX model (`n4ze3m/tiny-voca`) directly inside the APK assets for instant offline answer reading with zero data usage.
- **RAM Pre-Warming:** Pre-initializes the ONNX runtime session in memory on startup so reading aloud starts instantly with no cold-start lag.
- **Voice Customization:** Easily switch between **F2 (Female)** and **M2 (Male)** voices in Settings, and choose speech speed multipliers (1.0x, 1.25x, 1.5x).
- **Synchronized Live Word Highlighting:** Dynamic live word highlighting moves in real time with the audio, incorporating syllable-based duration calculation and natural pauses for punctuation (commas, periods, question marks).
- **Accidental Deletion Protection:** Added liquid-glass confirmation dialog before removing the voice model, with one-tap instant offline restoration from local APK assets.

### ⚡ Liquid-Glass Performance Benchmark Dialog
- **Revamped Dialog UI:** Replaced plain modal dialogs with a modern high-contrast `GlassDispersionCard` featuring active glass buttons and high-contrast labels.
- **Comprehensive Benchmarks:** Measures both cold and warm completion latencies with synthetic inputs.

### 🗂️ Model Manager & Reliability
- **Discoverable Voice Models:** Added `TinyVocaModelCard` directly to the Models tab and model search so voice capabilities are discoverable and manageable alongside LLMs.
- **Model Re-initialization Fix:** Resolved race condition when auto-unloading models after idle timeout, ensuring any model can be cleanly selected and initialized again immediately.
- **Soft Keyboard Retention:** Opening the model selector dropdown no longer dismisses the soft keyboard.

<h2>🚀 What's New & Improved</h2>

<h3>🚀 16 KB Native Memory Page Support</h3>
<ul>
<li>Eliminated the outdated 4 KB-aligned <code>libtensorflowlite_jni.so</code> runtime in favor of modern, 16 KB-compliant LiteRT-LM.</li>
<li>Added <code>-Wl,-z,max-page-size=16384</code> linker options to CMake for all native binaries.</li>
<li>Audited and verified all native shared libraries (<code>libsolus_llama.so</code>, <code>libLiteRt.so</code>, <code>liblitertlm_jni.so</code>, <code>libllm_inference_engine_jni.so</code>) for 16 KB / 64 KB ELF segment alignment.</li>
</ul>

<h3>📉 Footprint & Runtime Compression</h3>
<ul>
<li>Stripped 73 MB of emulator <code>x86_64</code> binaries from the APK, targeting pure 64-bit ARM (<code>arm64-v8a</code>).</li>
<li>Enabled native library compression via <code>useLegacyPackaging = true</code>, shrinking native libraries from 59 MB to 22.5 MB in the APK.</li>
<li>Configured full ProGuard / R8 rules preserving native JNI methods, callbacks, LiteRT-LM, MediaPipe GenAI, and PDFBox reflection.</li>
</ul>

<h3>🛡️ Zero Network Telemetry Purge</h3>
<ul>
<li>Removed Firebase Crashlytics and Google Services plugins from the project.</li>
<li>Added global Gradle exclusions blocking <code>firebase-measurement-connector</code>, <code>firebase-sessions</code>, <code>firebase-installations</code>, and ClearCut Telemetry (<code>transport-backend-cct</code>).</li>
<li>Cleaned AndroidManifest: removed <code>FirebaseInitProvider</code>, <code>SessionLifecycleService</code>, and Play Services metadata.</li>
<li>All crash logging is strictly on-device via Solus's local <code>CrashReportManager</code> with token redaction.</li>
</ul>

<h3>🧠 Query-Aware Memory Filtering</h3>
<ul>
<li>Refined memory retrieval so stored facts are only recalled when genuinely relevant to the conversation.</li>
<li>Universal persistence continues to function seamlessly across all GGUF, LiteRT, and MediaPipe models.</li>
</ul>

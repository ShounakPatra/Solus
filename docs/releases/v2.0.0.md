<h2>🚀 What's New & Improved</h2>

<h3>⚡ Vulkan Compute & Inference Engine</h3>
<ul>
<li>Integrated native Vulkan compute backend in llama.cpp JNI, enabling hardware GPU acceleration alongside CPU multi-threading.</li>
<li>Added dynamic fallback to CPU when Vulkan runtime features are unavailable on older devices.</li>
<li>Enhanced crash guards and device telemetry to monitor thermal limits and RAM availability in real-time.</li>
</ul>

<h3>📚 Local Retrieval-Augmented Generation (RAG)</h3>
<ul>
<li>On-device text chunking and vector embedding generation for attached files (PDF, DOCX, TXT, MD, Code).</li>
<li>Cosine similarity retrieval with adaptive thresholding to inject relevant context into model prompts.</li>
<li>Ask follow-up questions from previously uploaded documents across chat sessions without needing to re-upload.</li>
<li>Interactive RAG attribution pills displaying document source name and matching chunk percentage.</li>
</ul>

<h3>🧩 GGUF Architecture & Support</h3>
<ul>
<li>Initial native execution support for GGUF model formats, including Qwen 2.5 0.5B GGUF.</li>
<li><em>Note on Compatibility</em>: Currently, models like Llama 3.2 1B GGUF are not yet supported due to architectural requirements.</li>
<li>Full GGUF model support across all major architectures, memory optimizations, and extended model catalog are arriving in our major <strong>October update</strong>!</li>
</ul>

<h3>🎙️ Audio Recording & Playback</h3>
<ul>
<li>High-fidelity 16kHz PCM mono audio recording with interactive pause and resume controls.</li>
<li>Real-time loudness metering and recording waveform visualization.</li>
<li>In-composer audio preview player to listen to recordings before sending.</li>
<li>In-bubble audio player with seekable progress bar and playback duration indicators.</li>
</ul>

<h3>🔄 Automatic GitHub Release Updates</h3>
<ul>
<li>Integrated OTA update checker that compares current version against latest GitHub releases.</li>
<li>One-tap in-app APK download with real-time download progress.</li>
<li>Seamless launch into Android package installer without manual browser downloads.</li>
</ul>

<h3>📂 Document Attachment Cards & External Viewers</h3>
<ul>
<li>Color-coded file format badges for PDF, Word, Excel, Code, and Archives.</li>
<li>Direct integration with Android <code>FileProvider</code> to launch documents and images in default system apps.</li>
<li>Full image preview mode with quick-access external viewer shortcut.</li>
